# Full Stack Development Course — Landing Page

A responsive static webpage showcasing a **Full Stack Development Course**, built with semantic HTML5 and modern CSS3.

## Features

- **Course Overview:** Displays course duration (6 months), mode (Online + Offline), pricing with discount highlight (`<del>` and `<mark>`), and full description.
- **Structured Curriculum:** Color-coded sections covering Frontend, Backend, Databases, Programming Concepts, Course Modules, Technology Descriptions (`<dl>`), and Development Tools.
- **Logistics & Info:** Includes eligibility criteria, weekday batch schedules (Morning & Evening), important notes, and contact details.
- **Enrollment Form:** Interactive form with inputs for Name, Email, 6-digit numeric OTP validation, and PDF file upload.
- **Responsive Layout:** Uses Flexbox (`flex-wrap`) for images, fluid sizing (`min(100%, 500px)`), and a mobile media query (`max-width: 600px`).

## Tech Stack

- **HTML5** — Semantic structure (`<main>`, `<header>`, `<section>`, `<form>`)
- **CSS3** — Flexbox, linear gradients, box shadows, and responsive media queries
